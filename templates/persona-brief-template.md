# AI Persona / UGC Content Brief Template
### Paste this into Claude or ChatGPT to begin your production

---

> **How to use:**
> Fill in every field you know. Write `?` next to anything you're unsure about.
> Write `LOCKED` next to anything that must not be changed.

---

## THE CONTENT

```
Persona name:
Age:
Niche (fitness / beauty / food / tech / lifestyle / fashion):
Product or subject being reviewed (or write ? for a generic demo):
Platform (TikTok / Instagram Reels / YouTube Shorts):
Length (seconds — max 30 per Seedance block):
Tone in three words:
What the viewer should feel at the end:
```

---

## THE PERSONA

```
Built from:  real photos (upload 4) / written description

If written description — fill in:
  Face: (skin tone, jaw, eyes, nose, lips, brows, any distinctive features)
  Hair: (color, length, texture, styled / messy / tied up)
  Build: (visible from waist up — shoulders, posture)
  Wardrobe: (what they wear on camera — be specific about fabric and color)
  Energy: (low and dry / warm and chatty / deadpan / enthusiastic)
  Distinguishing feature: (tattoo, glasses, earrings, scar)

Skin type: (real texture — visible pores / faint freckles / natural flush — NOT airbrushed)
```

---

## THE PRODUCT / SUBJECT
*(Skip if no product)*

```
Product name (or invent one — no real brands):
What it looks like: (color, shape, packaging, label)
What it does:
One honest caveat about it:
```

---

## THE ENVIRONMENT

```
Location: (bedroom / kitchen / gym / car / outdoor / cafe)
Time of day:
Lighting feel: (warm tungsten vs cold window / hard daylight / soft overcast)
One specific detail that makes it feel real and lived-in:
Anything that must be in the space: (a table, a lamp, a rack, a bench)
```

---

## THE SCRIPT STRUCTURE

```
Hook (skeptical opener — not "hey guys"):
Specific detail (one concrete thing — not "omg I love it"):
Honest caveat (something that isn't perfect):
Verdict (sounds like they actually thought about it):
```

Or write `you decide` and the AI will write the full script from your brief.

---

## CAMERA FEEL

```
Shot on: phone (handheld, self-filmed) / propped camera / mix of both
Smoothness: real hand tremor / slightly crooked / organic drifts — NEVER tripod smooth
Speed: normal (no slow motion)
```

---

## SOUND

```
Voice: natural and warm / low energy and dry / slightly out of breath / casual
Music: none (recommended for UGC authenticity) / subtle background
Key sounds: (scoop against plastic / shaker lid / zip / barbell clang — name them)
```

---

## ANYTHING ELSE

```
(Notes, references, things to avoid, things that must be included)
Negative (things Seedance must NOT do):
```
